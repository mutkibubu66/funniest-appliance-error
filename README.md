## The line

> Error E04: I have washed this sock four times. It is still dirty. I refuse to wash it a fifth time.

One original one-line honest error message from a washing machine,
delivered deadpan in the machine's own flat, put-upon voice: it names a
real, plausible fault — a sock that will not come clean — and the laugh
comes from the truth of it, the machine quietly going on strike after
four honest attempts instead of pretending a fifth wash will help.
